# Security policy

This repository contains static data and a dependency-free browser interface; it does not accept credentials or process private learner data.

If a listed URL appears compromised, malicious, or deceptive, do not visit it again. Report it privately through [GitHub's security advisory form](https://github.com/studyarena-com/awesome-study-tools/security/advisories/new) and include the tool name, URL, and what you observed. For an ordinary broken link or rebrand, use the public listing-problem issue form instead.

Please do not include personal student information, access tokens, or sensitive browsing evidence in a public issue. Maintainers will remove unsafe links from the active catalog as soon as the report can be validated.
